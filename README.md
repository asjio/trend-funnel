# trend-funnel -- A股趋势筛选工作台

四层漏斗筛选 + 五层行动决策 + 卖出模拟。只分类不荐股, 所有判定原因由阈值确定性生成, 不经过LLM。

## 这不是什么

- 不是荐股工具, 不预测明天涨什么
- 不是长期持有策略, 是趋势跟随(典型持有2-10个交易日)
- 不保证赚钱, 它是风险管理工具: 让每次买入有理由、有止损、错了亏得有限

## 漏斗结构

```
第一层 大盘环境   指数>MA10 + 上涨宽度>55% + 涨停>8家 -> 强/正常/偏弱
第二层 板块强弱   行业+概念板块聚合: 正在加强(当日均涨+量比+上涨占比) / 持续强势(5日均涨+多周期全红)
第三层 个股筛选   只拉强板块成分股K线, 剔ST/新股/高价股/次新股
第四层 五类分类   决策树: 排除->高位->回调->启动->趋势, 每类带阈值触发原因
第五层 行动决策   评分0-100(趋势30+位置25+量能20+波动15+形态10) + 大盘加减分
                  四档: 可介入(>=72且位置<70分位) / 观察等待 / 不追高(位置>=90) / 回避
```

每只"可介入"股带完整交易计划: 参考介入价 / 止损价(max(MA20, 入场-2ATR), 幅度上限8%) / 四条卖出规则。

## 卖出规则(任一触发即卖, 收盘后判断)

1. 硬止损: 收盘跌破止损价
2. 移动止盈: 最高盈利达10%后, 从最高点回撤7%
3. 趋势破坏: 连续2日收盘低于MA10
4. 时间止损: 持有10个交易日盈利不足5%

历史复盘页会对每只可介入股做卖出模拟: 逐日回放K线判定卖出日/原因/收益率, 绿底赚红底亏。

## 运行

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install fastapi uvicorn requests -i https://pypi.tuna.tsinghua.edu.cn/simple
.venv/Scripts/python.exe -m funnel.web   # http://127.0.0.1:8768
```

**运行时机: 每个交易日收盘后(15:30之后)**。盘前量比为0, 盘中数值未定稿。每次运行自动归档到 `data/history/YYYY-MM-DD.json`, 复盘对账基于归档数据。

所有阈值在 `funnel/config.py`。

## 已知坑

1. 盘前(9:30前)快照lb=0: 板块量比条件豁免, 个股量比用K线"昨量/前5日均量"兜底
2. 盘前zxj==K线最后收盘时不重复追加, 否则多周期涨幅错位一天
3. K线一律剥离今日行(收盘后腾讯聚合有延迟)
4. 对账时点不同会导致价格漂移0.1-1.2%, 非算法bug
